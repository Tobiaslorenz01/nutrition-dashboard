# Screenshots

In diesem Ordner (`assets/`) werden die Dashboard-Screenshots abgelegt, die im
README oder in der Repo-Beschreibung eingebunden werden.

## Vorgeschlagene Dateinamen

| Datei                       | Inhalt                                    |
|-----------------------------|-------------------------------------------|
| `screenshot-iphone.png`     | Dashboard-Ansicht auf dem iPhone (PWA)    |
| `screenshot-desktop.png`    | Dashboard im Desktop-Browser              |
| `screenshot-home-screen.png`| App-Icon auf dem iPhone-Home-Bildschirm   |

## Empfohlene Auflösungen

| Gerät          | Auflösung (px)        | Hinweis                                  |
|----------------|-----------------------|------------------------------------------|
| iPhone         | 1170 × 2532           | Portrait, iPhone 12/13/14 (Retina)       |
| iPhone (klein) | 1080 × 2340           | Portrait, kompaktere Modelle             |
| Desktop        | 1920 × 1080           | Querformat, Vollbild-Ansicht             |

Format: PNG (verlustfrei, scharfe Texte). Dateien einfach in diesen Ordner
legen und im README über den jeweiligen Pfad einbinden, z. B.
`assets/screenshot-iphone.png`.
